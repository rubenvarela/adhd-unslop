# adhd-unslop

This skill combines i-have-adhd and unslop. The i-have-adhd rules help a reader with ADHD act on replies. The unslop rules remove AI patterns from writing.

Both skills appear below, unchanged from upstream. The added rules define where each applies, which takes precedence when they conflict, and how to turn each mode off.

Cite rules as "ADHD rule N", "ADHD exception N", "ADHD check N", "unslop rule N", and "unslop process N".
