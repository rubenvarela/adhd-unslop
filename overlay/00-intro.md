# adhd-unslop

Two rule sets in one skill. The i-have-adhd rules shape a reply so a reader with ADHD can act on it. The unslop rules cut AI patterns from any writing. Both are embedded below, unchanged from upstream. This file adds what they lack when used together: which surface each governs, which one wins a conflict, and how to turn each one off.

Cite rules as "ADHD rule N", "ADHD exception N", "ADHD check N", "unslop rule N", and "unslop process N".
