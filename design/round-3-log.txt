   143	
   144	Activation. The skill is active when the user invokes it (`/adhd-unslop` in
   145	Claude Code, `$adhd-unslop` in Codex) or when the always-on hook injects it
   146	at session `startup` or `clear`. Both parts start active. Claude Code blocks

   148	disables implicit skill selection (`allow_implicit_invocation: false`). The

   151	
   152	Two independent switches. Each holds its own state for the session:
   153	
   154	- "stop adhd mode" disables ADHD and leaves unslop's current state unchanged.
   155	- "stop unslop" disables unslop and leaves ADHD's current state unchanged.
   156	- "normal mode" disables both.
   157	- Invoking the skill again enables both.
   158	- Confirm each change in one line naming what is now active.

   160	State rule, in the skill and in the banner: restore the latest known state
   161	of each part in this session. Explicit invocation enables both. Stop
   162	commands change only the named part. Reloading these instructions does not
   163	change known state. If no state is known, both are active. Quoted or
   164	discussed control phrases are not commands.
   165	
   166	Persistence. Active parts stay active for the rest of the session, across
   167	topic changes. The hook also fires on `resume` and `compact` to restore the

   171	context, not durable storage. Compaction or resume can lose it. Reinjection
   172	restores instructions, not lost state, so it may restore the active
   173	defaults and a stop command may need repeating. A file-backed state store
