# adhd-unslop

This skill combines i-have-adhd and unslop:

- i-have-adhd helps a reader with ADHD act on replies
- unslop removes AI patterns from writing

Both skills are used unchanged from upstream, and their texts are part of these instructions. The added rules cover:

1. Where each mode applies
2. Which mode wins when they conflict
3. How to turn each mode off
